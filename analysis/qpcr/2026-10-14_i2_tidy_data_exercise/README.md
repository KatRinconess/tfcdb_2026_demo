# Tidy qPCR data from Lecture 3 exercise

Converted the Lecture 3 qPCR workbook into a tidy table with one row per well of one plate. The seven columns are `plate`, `well`, `amplicon`, `sgrna`, `treatment`, `cq`, and `note`. The result is in `tables/tidy_data.csv`.

**Software:** Microsoft Excel (reshaping and CSV export) and VS Code (editing and git).
