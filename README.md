# tfcb_2026_demo

This repository is a demo project for the TFCB 2026 course. It holds my experiment logs and a tidy qPCR dataset. Made by `KatRinconess`.

## Folder layout

- `README.md`: this file
- `experiments/`: dated experiment logs named `2026-10-14_i1_<short_description>.md`
  - `img/`: images used in the logs
- `analysis/qpcr/2026-10-14_i2_tidy_data_exercise/`: the tidy data exercise
  - `README.md`: what was done, software used, and changelog
  - `data/`: README linking the original workbook
  - `tables/`: the derived `tidy_data.csv`
